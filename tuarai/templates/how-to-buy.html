⚡ ขั้นตอนการสั่งซื้อและสร้างเว็บเซอร์ไพรส์

เลือกเว็บ ใส่รูป ดูตัวอย่างก่อนจ่าย แล้วรับ QR Code ไปมอบให้แฟน ทำตามขั้นตอนด้านล่างนี้ได้เลย

01

สมัครสมาชิก / เข้าสู่ระบบ

กดปุ่ม "เข้าสู่ระบบ / สมัครสมาชิก" มุมขวาบน เพื่อสร้างบัญชีสำหรับจัดการเว็บเซอร์ไพรส์ของคุณ

02

เลือกเว็บที่ถูกใจ

กด "ดูตัวอย่างเว็บ" เพื่อลองเล่นของจริงก่อน แล้วกด "เลือกซื้อเว็บนี้" ซื้อ 1 ครั้งได้ 1 เว็บ ถ้าอยากได้เว็บอื่นเพิ่มก็ชำระเงินใหม่ได้เลย

03

เลือกแพ็กเกจ Basic หรือ Pro

Basic {{ '{:,.0f}'.format(themes[0].prices.basic) if themes else '' }} ฿ — {{ features.basic|join(' · ') }}
Pro {{ '{:,.0f}'.format(themes[0].prices.pro) if themes else '' }} ฿ — {{ features.pro|join(' · ') }}

04

กรอกข้อมูลและอัปโหลดรูป

ใส่ชื่อแฟน วันที่เริ่มคบกัน จดหมาย และรูปความทรงจำ (อย่างน้อย {{ min_photos }} รูป) รูปแรกจะเป็นรูปหน้าปกและรูปใหญ่ตรงกลาง

05

ดูตัวอย่างเว็บจริงก่อนชำระเงิน

ระบบสร้างเว็บให้ดูก่อนโดยยังไม่เสียเงิน ถ้ามีตรงไหนไม่ถูกใจกดแก้ไขได้เลย พอใจแล้วค่อยกดชำระเงิน

06

ชำระเงินผ่านพร้อมเพย์ (PromptPay)

สแกน QR พร้อมเพย์ตามยอดที่ระบุ แล้วแนบสลิป ระบบจะตรวจสอบและเปิดใช้งานเว็บให้

07

รับ QR Code ไปมอบให้แฟน!

ดาวน์โหลด QR Code ไปพิมพ์ใส่การ์ดหรือกล่องของขวัญ แฟนสแกนแล้วเปิดเว็บได้ทันที แพ็กเกจ Pro เลือกสไตล์ QR ตกแต่งได้ และมีปุ่มคัดลอกลิงก์สำรองไว้ส่งทางแชท

⚠️ ข้อตกลงการใช้งาน: สินค้าเป็นบริการดิจิทัล ชำระเงินแล้วไม่รับคืนเงินทุกกรณี แพ็กเกจ Basic แก้ไขข้อมูลได้ภายใน {{ packages.basic.edit_hours }} ชั่วโมงแรกหลังชำระเงิน และใช้งานได้ {{ (packages.basic.valid_days // 365) }} ปี (ต่ออายุได้ {{ '{:,.0f}'.format(renew_price) }} ฿ / ปี) ส่วนแพ็กเกจ Pro แก้ไขได้ไม่จำกัดตลอดอายุการให้บริการ
